# 作業記録(worklog)

FITOM_Xの変更・修正・調査の経緯を、月ごとに1ファイルで置く。現在の実装状況は
`docs/STATUS.md`に書き、そこに至った経緯はここに書く。

- ファイル名は`YYYY-MM.md`。表の1行が1件の変更・修正・調査
- 行をどの月に置くかは、その行に書かれた最初の日付で決める
- 新しい記録は、該当する月のファイルの末尾に足す

## 2026年7月〜10月の行について

これらの行は`docs/STATUS.md`から文言を変えずに移したもので、行の並びは移す前の
STATUS.mdでの並びのまま(日付順ではない)。行の中の「上記」「下記」「上の表」は
移す前のSTATUS.md内の位置関係を指すため、別の月のファイルや`docs/STATUS.md`に
残った行を指していることがある。移す前の版は、このREADME.mdを追加したコミットの
親で読める(`git log --diff-filter=A -- docs/worklog/README.md`)。
