# FITOM_X SMF→WAV 変換(`fitom_render`)リファレンス

`fitom_render`は、指定したプロファイルでSMF(スタンダードMIDIファイル)を演奏し、その音をWAVファイルに書き出すコマンドです。画面も音声デバイスも使いません。実際の再生時間を待たずに、計算できる速さで書き出します。

---

## 1. 使える条件

プロファイルの`hw_plugins`に並ぶHWプラグインが、**すべて**オフライン描画に対応している必要があります。エミュレータやSoundFont音源のように、プラグインの中で音を作るものが対象です。実機のチップを鳴らすプラグインは、音を取り込む手段が無いので使えません。

対応していないプラグインが1つでもあれば、変換せずに終了し、そのプラグインの名前を表示します。プロファイルにHWプラグインが1つも無い場合も、変換しません。

---

## 2. 使い方

```
fitom_render <profile.json> <input.mid> <output.wav> [--rate 44100] [--format s16|s24|f32] [--tail 3.0]
```

| 引数 | 既定値 | 内容 |
|---|---|---|
| `<profile.json>` | — | 演奏に使うプロファイル |
| `<input.mid>` | — | 変換するSMF |
| `<output.wav>` | — | 書き出すWAVファイル。既にあれば上書きします |
| `--rate` | `44100` | 出力のサンプルレート(Hz)。8000〜384000 |
| `--format` | `s16` | WAVの形式。`s16`=16bit整数、`s24`=24bit整数、`f32`=32bit浮動小数 |
| `--tail` | `3.0` | SMFの最後のイベントの後に、書き出しを続ける秒数。リリースの余韻を残すために使います |

- 出力は常にステレオです
- 音量が最大を超えた部分は、`s16`と`s24`では最大値で切り詰めます。`f32`では切り詰めずにそのまま書きます
- 書き出せるのは、WAVファイルの上限(4GiB)までです
- 終わると、書き出したファイル名、長さ(秒)、サンプルレートを表示します

---

## 3. SMFの扱い

- 読めるのはフォーマット0と1です。フォーマット2は読めません
- 全トラックのイベントを時刻順に並べて演奏します。同じ時刻のイベントは、トラックの順、トラック内の順に送ります
- テンポ変更に従います。テンポ指定が無い間は120BPMです。分解能がSMPTE形式(フレーム単位)のSMFでは、テンポ変更は使いません
- 各イベントを送るMIDI入力(MPU)は、SMFのMIDI Portメタイベント(`FF 21`)で決まります。MIDI Portがあると、そのトラックのそれ以降のイベントを、値と同じ番号のMPUへ送ります(0ならMPU0、3ならMPU3)。MIDI Portより前のイベントと、MIDI Portの無いトラックのイベントは、MPU0へ送ります。MIDI Portは、それが置かれたトラックにだけ効きます
- MIDI Portの値が4以上のイベントは送らずに捨てます。捨てたときは、MIDI Portの値ごとに、捨てたイベントの数を警告として表示します。そのトラックのテンポ変更には従います
- プロファイルの`midi_inputs`は使いません。実際のMIDIポートは開かず、MPU0〜MPU3を常に使えます
- Device Nameのメタイベント(`FF 09`)は読みません
- シーケンサによっては、トラックの出力ポートの設定をSMFに書き出しません。MPU0以外へ送りたいトラックには、先頭にMIDI Portメタイベントを置いてください
- チャンネルメッセージとシステムエクスクルーシブを送ります。それ以外のメタイベント(歌詞・マーカー等)は使いません
- イベントは64サンプル単位で送ります。各イベントは、その時刻以降で最初の64サンプルの区切りで送ります(44.1kHzで最大約1.45ミリ秒、48kHzで最大約1.33ミリ秒遅れます)。すべての音源に同じ区切りで送るので、音源の間で発音の時刻は揃います。時間とともに変化する処理(ソフトウェアLFO等)は、リアルタイムで演奏するときと同じく1ミリ秒ごとに進みます

---

## 4. ログ

`fitom.conf.json`(実行ファイルと同じディレクトリ)の`log`の設定に従います。無い場合の既定値は、level=info、ファイル`fitom_render.log`です。コンソールには出しません(`log.console`を`true`にすると出します)。変換の結果とエラーは、ログとは別に、常にコンソールに表示します。
